口诀与藏头

分
分界在主——「这真是那先知」「这是基督」「不是」。约7:40–43；太10:32–33。
剑
剑是圣道——神的道比两刃的剑更快（来4:12）；不是人的刀（太26:52）。
合
合在真道——分开是为了招聚：「在真信心上合一」（HC 54；约17:17，21）。
安
安在父手——麻雀与头发（太10:29–31）；为主失丧的必得着（10:39）。

口诀：「分·剑·合·安」——分界线是基督，剑是圣道，目的是合一，信徒得平安。

四个闭环

① 救赎史闭环

创3:15 → 该隐与亚伯 → 以撒/以实玛利、雅各/以扫 → 大卫/押沙龙 → 基督「动刀兵」→ 十字架 → 教会 → 末日分开 → 新天新地。

② 圣约神学闭环

恩典之约中的两种后裔 → 同受记号，不同回应 → 约的祝福与咒诅 → 新约中仍有麦子与稗子 → 末日分开。

③ 圣经神学闭环

「分开」之线：光与暗 → 圣与俗 → 利未人的分别 → 两刃的剑 → 绵羊与山羊 → 「不再有黑夜」（启22:5）。

④ 罪—救赎—感恩

点一（人心恨神，不信者分开）→ 点二（基督藉道与灵赐信心）→ 点三（认主、背十字架、保守合一）。HC 问2 的三件事。

翻转卡片（点击翻面）

10:34 的「刀」是什么意思？点击翻面
比喻分开，不是战争；路12:51 说「乃是叫人纷争」。门徒不是拿刀的人，而是被刀分开的人。
约7:43 与林前1:10 有何关系？点击翻面
同一个字 schisma：一个因着耶稣（神所定），一个因着人（神所禁）。
「目的」还是「结果」？点击翻面
10:34 用「来……叫」的语气：分开在神的旨意之中，但罪责在不信的人（CD I.15；III/IV.9）。
为什么「甚至在教会中」？点击翻面
约7的群众是守节的立约百姓；十二人中有犹大；有形教会中有假冒为善的人（BC 29；约壹2:19）。
10:23 的「人子到来」？点击翻面
主要三说：复活后得权柄（28:18）、主后70年审判、或末日再来（宣教持续到那时）。宜谦卑持守，不作定论。
什么时候可以离开一个教会？点击翻面
按BC 28–29：当它不再有真教会的标志；不可因偏好私自离开，要按合乎秩序的途径。
